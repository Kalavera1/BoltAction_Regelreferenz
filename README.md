# Bolt Action v3 – Regelreferenz

Eine kleine, private Ein-Seiten-Webseite mit **eigenen, frei formulierten
Notizen** zu den Bolt-Action-v3-Regeln, bei denen am Spieltisch am
häufigsten nachgeschlagen werden muss:

- **Transporter** – Einsteigen, Aussteigen bei Zerstörung, Nahkampf gegen
  einen beladenen Transporter
- **Häuser** – Assault aus/in ein Haus, Panzer gegen Haus, Stockwerk
  wechseln, Flammenwerfer gegen Haus
- **Nahkampf** – kompletter Ablauf, Sonderfälle gegen Transporter/Häuser,
  Panzerjäger/Panzergranaten gegen Panzer

Gedacht als schneller Link-Spickzettel per Smartphone/Tablet am Tisch,
nicht als Lernwerkzeug oder Ersatz fürs Regelbuch.

## Urheberrecht

*Bolt Action* (3. Edition) ist ein Tabletop-Regelwerk von **Warlord Games
Ltd.** Diese Seite enthält **keine** Original-Texte, Tabellen oder
Abbildungen aus dem Regelbuch – nur eine eigene, umformulierte
Zusammenfassung der Spielmechanik zum persönlichen Gebrauch, mit
Seitenangaben zum Abgleich mit dem eigenen, offiziell erworbenen
Regelbuch. Das PDF des Regelbuchs selbst wird **nicht** in diesem Repo
gehostet oder verlinkt.

Bolt Action, Warlord Games und alle zugehörigen Logos/Markennamen sind
Eigentum von Warlord Games Ltd. Diese Seite steht in keiner Verbindung
zu Warlord Games und erhebt keinen Anspruch auf Vollständigkeit oder
Korrektheit – im Zweifel gilt immer das offizielle Regelbuch.

## Technik

Statische Seite (`index.html`, kein Build-Schritt), gehostet über
GitHub Pages. Suche/Filter und Hell/Dunkel-Umschaltung laufen komplett
clientseitig in Vanilla JS.
